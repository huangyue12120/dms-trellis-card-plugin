# Trellis DMS v1.0.0 candidate

**Status: candidate; not a stable release.** This package targets DMS `>=1.6.2`.
The manifest version is `1.0.0`.

## Included

- Read-only Trellis project and task status in a shared DMS snapshot.
- Bar widget and popout, Desktop widget, Simplified Chinese translations, and
  the optional `!trellis` Launcher surface.
- Manifest permissions: `settings_read`, `settings_write`, and `process`; no
  network permission is declared.

## Acceptance status

Repository fixture and static checks are recorded as passing. They do not
establish successful loading and behavior in a live DMS session. Required DMS
1.6.2 host acceptance remains pending for core discovery, refresh, recovery,
multi-surface lifecycle, and the retained optional surfaces:

- Desktop placement, resizing, scrolling, and disable behavior.
- DMS locale switching between `zh_CN` and English, fallback, and layout.
- Launcher `!trellis` search, selection, State persistence, and popout
  behavior. The latest startup report showed the bar widget and daemon loaded,
  but the trigger has not been exercised in the DMS Launcher search field.

The candidate must not be described as stable until the required host gates
pass or an optional surface is removed and core host acceptance is completed.
See the final acceptance evidence in the repository's Trellis task records.

## Install and rollback

Extract the release ZIP and place its `TrellisDms/` directory at
`$CONFIGPATH/DankMaterialShell/plugins/TrellisDms` (usually
`~/.config/DankMaterialShell/plugins/TrellisDms`). Enable or reload it in DMS
Plugin settings; restart DMS if its plugin scanner does not detect the change.
To roll back, restore the prior plugin directory and reload DMS. See the root
README for the full instructions.

After this candidate is merged to `main`, a matching `v1.0.0-rc.N` tag makes
the workflow create a GitHub pre-release containing this ZIP. No tag or
release has been created. The workflow does not publish or submit the plugin
to the DMS online registry/search list.
