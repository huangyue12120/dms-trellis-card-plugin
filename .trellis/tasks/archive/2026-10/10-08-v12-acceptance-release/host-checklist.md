# Remaining Supported-host Checks

Record the candidate file hashes, DMS version, locale, surface instances, and
time with each result. A user-observed result is recorded as such; repository
fixtures and successful component loading remain separate evidence classes.
The current status of every unexecuted item is UNVERIFIED. The user later
reported overall manual acceptance and requested archival; detailed item-level
results were not supplied. Installed candidate bytes and later native loading
were independently verified. Archival does not infer passes for this checklist.

1. Open the normal popout at normal and narrow widths. Traverse query, scope,
   clear, results, continuation, history, Back, and quick actions with Tab and
   Shift-Tab. Verify visible focus and scrolling; Return/Space activate native
   controls and Escape preserves the host close behavior.
2. Open Recent Trellis Changes. Initial/reloaded facts are quiet, later reliable
   status/session/selection changes have qualified context, and identical facts
   do not repeat. Degraded reads/recovery do not manufacture completed tasks or
   rediscovery. Compare two widget instances against the same daemon history.
3. Search project name, task title, and task ID in Live, Archive, and All. Include
   equal IDs/titles in separate projects. Typing preserves filter/pin; selecting
   a project uses its existing filter and selecting a task opens detail without
   auto-pinning. Clear immediately restores the current projection.
4. In a large archive, inspect partial/no-match/Continue/terminal-cap text. Open
   detail, return to search, and exercise the resulting continuation/retry.
   Change query/scope or close while loading. With two widgets, a superseded
   request stops loading and stale replies do not replace current results.
5. Copy live/archive task IDs and project/task paths. Compare actual clipboard
   content with displayed IDs and freshly resolved canonical paths. Include
   spaces, non-ASCII text, and URL reserved characters. Open each folder and
   verify accepted-launch feedback separately from the observed window target.
6. Verify removed roots, stale/ambiguous identities, traversal, and symlink
   escapes are rejected with local feedback. Clipboard/opener failure does not
   change Snapshot/Health or prevent detail/Back. Use disposable fixtures for
   malformed data; do not modify real tasks merely to provoke a failure.
7. Regress bar orientation/modes, popout grouping/filter/pin, archive browsing,
   Markdown, Settings, `!trellis` Launcher, and Diagnostics redaction/copy.
   Verify Desktop Overview/Tasks/Health and two independent placements sharing
   the same Snapshot and one watcher registry.
8. Carry forward the v1.1 host gates: settings save keeps Desktop available,
   manual refresh discovers new tasks, automatic topology refresh follows the
   configured interval, locale switching, reload, disable/enable, and DMS
   restart. Record preference persistence separately because the installed
   DMS State writer has a previously observed error.

Stable v1.2.0 requires passing the required matrix, matching manifest/package,
reviewed source ancestry/tag validation, and publication evidence. A successful
reload or fixture suite alone does not close these gates.
